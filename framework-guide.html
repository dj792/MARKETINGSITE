What the framework is

One structure. Three names. Keep them straight.

The structure

Executive Visibility Framework

The categories where CEOs need visibility. It defines what we measure and keeps product, messaging, and assessment aligned.

The tool

Executive Visibility Assessment™

The self-assessment that measures how much timely, trustworthy visibility a CEO actually has across every category.

The result

Executive Visibility Score™

The 0–100 result the assessment produces, mapped to one of the maturity levels below.

Every category ladders into the Brand North Star: Trusted Data → Executive Visibility → Executive Intelligence → Executive Partnership → Better Decisions → Organizational Growth. The framework is where "Executive Visibility" becomes concrete — the specific areas a CEO must be able to see. When we build a dashboard, write a page, or answer a prospect, it should map back to one of these categories.

How scoring works
Each question is answered Yes / No and carries a weight set in the workbook. A category's score is its earned points ÷ applicable points × 100; those roll up into the overall Executive Visibility Score™ — a 0–100 result mapped to the maturity levels below.
